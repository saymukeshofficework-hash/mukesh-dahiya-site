# Resource files

Place uploaded PDFs/files here, organized by type:

```
public/resources/
  notes/
  solutions/
  questions/
  previous-papers/
  worksheets/
  courses/
  paid-notes/
  neet/
```

Reference the file path in the matching entry's `file` (or `previewFile`)
field in `src/data/*.ts` — no page code needs to change.
